# CGPA Calculator

Task from the **CodeAlpha C++ Programming Internship** by Himanshu Srivastava.

A console program that calculates semester GPA and overall CGPA on a 10-point scale.

## Features
- Multiple semesters and courses
- Letter grades (O, A+, A, B+, B, C, P, F) or numeric grade points
- Credit-weighted grade points, per-semester report table
- Input validation for every field

## How to run
```bash
g++ -std=c++17 main.cpp -o app
./app        # on Windows: app.exe
```

## Tech
C++17, standard library only.
